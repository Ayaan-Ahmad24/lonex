# LONEX Generated Image Pack

This ZIP contains 20 locally usable WebP images prepared from AI-generated visual boards for the LONEX public website redesign.

## Folders
- `hero/` — homepage and brand-story imagery
- `categories/` — solar, storage and electric-mobility category imagery
- `about/` — company-story and commercial-context imagery
- `lifestyle/` — installation, charging, production and family/lifestyle scenes
- `editorial/` — blog and editorial imagery
- `demo-products/` — illustrative concept images for temporary demo CMS product records

## Installation
Copy the `lonex-generated-images` folder into the LONEX project's `public/images/` directory, or copy its subfolders into `public/images/lonex-generated/`.

Example local path:
`/images/lonex-generated/categories/solar-panels.webp`

## Accuracy and publishing rules
- These are AI-generated illustrative visuals. They are not photographs of verified LONEX inventory, actual LONEX premises, real staff, authorized dealers, or specific manufacturer models.
- Every image under `demo-products/` is strictly for temporary demo content and must be visibly labelled “Illustrative demo product” (or equivalent) in the website UI.
- Do not use these images to substantiate actual technical specifications, certifications, warranties, stock availability, manufacturer identity, or performance claims.
- Use the official LONEX logo as a separate website asset; do not rely on text/logos rendered inside generated imagery.
- Replace demo product images with approved manufacturer/product photography before production launch.
- All assets are WebP and stored locally. No external image URLs are required.
- `ASSET_MANIFEST.csv` lists each asset, dimensions and suggested use.
